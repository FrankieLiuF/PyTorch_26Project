Hepatitis已经被编码encoding：
就像文档里描述的，它的特征可以分为两类：
-数值型特征 (Numerical)：像是年龄、胆红素等检查指标，这些是连续变化的数字。
-分类型特征 (Categorical)：像是否有乏力、肝肿大等症状，本质上是“Yes/No”的类别。为了方便机器学习处理，这些类别被转换成了数字，比如用 1 代表“是”，2 代表“否”。所以你看不到文字，只看到数字，但这个数字是类别的“代号”，不是数值本身。

Lenses情况类似，所有特征都是类别。这也是为什么我们在导入数据后，需要明确告诉模型哪些列是数值、哪些是类别，因为它们的处理方式（比如归一化）很不一样。

5. Statistical Test 统计测试
使用Wilcoxon Signed-Rank Test ，用于比较两个配对组之间是否有显著差异。

推荐方案：使用一个统一的CSV存储所有结果，然后从中提取配对数据进行比较。
results.csv 结构：
fold, method, model, accuracy, f1_score, auc_roc, seed, epochs

示例数据：
0, tinto, efficientnet_v2_m, 0.7667, 0.7600, 0.8500, 42, 50
1, tinto, efficientnet_v2_m, 0.7333, 0.7200, 0.8300, 42, 50
2, tinto, efficientnet_v2_m, 0.8000, 0.7900, 0.8700, 42, 50
0, igtd, efficientnet_v2_m, 0.7333, 0.7200, 0.8400, 42, 50
1, igtd, efficientnet_v2_m, 0.7000, 0.6900, 0.8200, 42, 50
...

做完实验后，你不能只凭“A模型比B模型高0.5%”就说A更好 ，因为可能有随机性。
- 使用 Friedman Test + Nemenyi Post-hoc Test 或 Wilcoxon Signed-Rank Test。（这部分待了解）
- 这些检验能告诉你：模型之间的性能差异是统计显著的还是由于随机种子造成的波动。


类比：A 和 B 投篮，A 投了 10 中 5，B 投了 10 中 6。B 命中率更高，但样本太小，我们不确定 B 是真的更准还是运气好。统计检验就是告诉我们"这差距可信吗"。

统计测试需要：
所有模型的完整结果（5折CV的准确率列表）
多种转换方法的结果
多个数据集的结果（如果是跨数据集对比）

Step 1：Compare What
在你的实验中，你会比较：
不同转换方法（IGTD vs TINTO vs SuperTML）
不同模型（ResNet-18 vs MobileNet）
不同策略（特征提取 vs 微调）

每种组合在多个数据集上运行多次（比如 5-Fold CV），得到多组成绩。
交叉验证的解决方案：不固定一个测试集，而是循环 K 次，每次用不同的数据做测试，最后取平均。这样评价结果更稳定、更可靠。

Step 3：选择检验方法
比较类型	推荐检验	说明
比较两种方法（如 IGTD vs TINTO）	Wilcoxon Signed-Rank Test	非参数检验，不要求数据正态分布，适合小样本
比较多种方法（如 4 种转换方法）	Friedman Test + Nemenyi Post-hoc Test	先用 Friedman 判断"整体有没有差异"，再用 Nemenyi 找出"哪两两之间有差异"

为什么不用 t-test？ t-test 要求数据服从正态分布，在机器学习实验中往往不满足。Wilcoxon 和 Friedman 是非参数检验，没有这个要求，更适合。

解读 p-value：
p < 0.05：有 95% 的把握认为差异是真实的，显著。
p < 0.01：有 99% 的把握，非常显著。
p >= 0.05：差异可能只是随机波动，不显著。
