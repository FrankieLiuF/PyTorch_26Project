# Third-party Software

## TINTOlib

This repository includes TINTOlib, which provides the tabular-to-image
transformation implementations used in the experiments.

TINTOlib was developed by its original authors and is distributed under the
Apache License 2.0. The original licence is retained in
[`TINTOlib/LICENSE`](TINTOlib/LICENSE).

- Project: https://github.com/oeg-upm/TINTOlib-Documentation
- Licence: Apache License 2.0
- Citation: J. Liu, D. Gonzalez-Fernandez, M. Castillo-Cara, and R. Garcia-Castro,
  "TINTOlib: A Python library for transforming tabular data into synthetic
  images for deep neural networks," *SoftwareX*, vol. 32, Art. no. 102444,
  2025. https://doi.org/10.1016/j.softx.2025.102444

The bundled TINTOlib source was not modified. Project-specific configuration,
integration, preprocessing, training, caching, evaluation, and result analysis
were implemented separately in this repository.
